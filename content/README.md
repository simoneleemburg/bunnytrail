# content/

This is the canonical worldbuilding data. Every entity is a pair:

- `<type>/<slug>.yaml` — structured metadata (name, tags, relations, …)
- `<type>/<slug>.md` — long-form prose

Entity ids are `<type>/<slug>`. Reference other entities from prose with
wikilinks: `[[characters/kael-of-the-third-veil]]` or
`[[characters/kael-of-the-third-veil|Kael]]`.

Edit in your IDE. Save. The site picks up changes on the next request.
